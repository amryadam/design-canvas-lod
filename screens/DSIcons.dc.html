Design system · 04

Iconography

A stroke set drawn to one weight, replacing ng-zorro’s filled outlines everywhere. Fifty-nine names today; each new one is added to the same file.

Anatomy

  • 24-unit grid with a 2-unit safe area on every side; the drawing lives in the inner 20.
  • One weight: 1.6 stroke, round caps, round joins. No fills, no two-tone, no 1px details.
  • Registered under ng-zorro’s own names, so the select caret, the password eye and the modal close come out in this style without a template changing.
  • Colour comes from currentColor: an icon is ink beside body text, faint beside a label, and the state colour inside a banner.
  • Never emoji, never a dingbat. A missing icon is drawn, not borrowed from another set.

Sizes

16 · inline with 13px text
18 · menu rows, inputs
20 · buttons, icon buttons
24 · the rail, empty states
